# TreeCost

Sistema de gerenciamento de fórmulas e custos de produtos
desenvolvido em Java para a disciplina de Estruturas de Dados II.

## Funcionalidades

- Cadastro de produtos e componentes
- Árvore genérica de composição de produtos
- Explosão de produtos
- Cálculo de quantidades e custos de aquisição
- Atualização de preços
- Implosão e recálculo de custos
- Interface gráfica
